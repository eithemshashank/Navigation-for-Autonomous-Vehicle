# Navigation for Autonomous Vehicle

A real-time autonomous navigation assistance system developed using **Python**, **OpenCV**, and **YOLOv8**. The project analyzes live video streams to detect vehicles, pedestrians, and obstacles, performs road segmentation, and generates navigation commands such as **STOP**, **LEFT**, **RIGHT**, and **FORWARD**. It demonstrates the application of computer vision and deep learning techniques for intelligent transportation and autonomous driving assistance. :contentReference[oaicite:0]{index=0}

## Features
- Real-time object detection using YOLOv8
- Road segmentation for drivable path identification
- Live video processing with OpenCV
- Navigation command generation (STOP, LEFT, RIGHT, FORWARD)
- Decision-making based on obstacle position and road conditions
- Real-time visualization of detections and navigation output

## Tech Stack
- Python
- OpenCV
- YOLOv8
- NumPy
- Computer Vision
- Deep Learning

## Applications
- Autonomous vehicle navigation
- Advanced Driver Assistance Systems (ADAS)
- Traffic monitoring
- Robotics and smart navigation
